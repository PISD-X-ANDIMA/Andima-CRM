# Release Notes

## 2026-10-09

### Dashboard and schedule

- The Sales Executive weekly schedule displays up to five upcoming meetings instead of two, with the meeting date and time range.
- A notice appears when a scheduled meeting starts within the next hour.
- The schedule loading state now reserves space for five rows.

### Exports

- Dashboard and Company List exports now share a cleaner spreadsheet layout with readable column widths and filters.
- PDF exports use a landscape, print-ready table with repeating column headings and page breaks handled by the browser. Choose **Save as PDF** in the print dialog.

### Company and meeting actions

- Meeting deletion now uses an in-app confirmation dialog rather than the browser's default confirmation popup.
- Company List loading now shows a table-shaped skeleton matching its columns and rows.

### PIC phone numbers

- Add/Edit Company now provides a country calling-code selector for Indonesia, the United States, the United Kingdom, Singapore, Malaysia, and Australia.
- The input limits the number of digits based on the selected country and saves the number in international format.

### Language

- User-facing validation and failure messages touched by these changes use English, consistent with the application language.

### Notes

- PDF creation opens the browser print dialog; the user must choose the PDF destination to save the file.
- Country-code selection is available in the Company Add/Edit form. Other phone inputs have not been converted in this release.
